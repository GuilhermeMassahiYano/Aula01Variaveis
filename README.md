## 📖 Manual de Formatação Markdown (.md)

Arquivos `.md` (Markdown) são usados para documentar projetos de forma simples. Abaixo estão os principais comandos:

### 1. Títulos
Use `#` para títulos:
- `# Título Principal`
- `## Subtítulo`
- `### Tópico`

### 2. Ênfase
- **Negrito**: `**texto**`
- *Itálico*: `*texto*`
- `Código`: Use crases (backticks)

### 3. Listas
- **Não ordenada:** Use `-` ou `*`
- **Ordenada:** Use `1.`, `2.`

### 4. Links e Imagens
- **Link:** `[Texto do Link](https://google.com)`
- **Imagem:** `![Texto alternativo](url-da-imagem.jpg)`
